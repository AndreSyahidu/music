CARA MENGGUNAKAN FOLDER UPLOADS
================================

1. Setiap folder di dalam /uploads akan menjadi satu playlist otomatis
2. Nama folder = Nama Playlist
3. Upload file MP3, WAV, OGG, M4A, atau FLAC ke dalam folder playlist

CONTOH STRUKTUR:
----------------

/uploads/
  ├── lofi/
  │   ├── song1.mp3
  │   ├── song2.mp3
  │   └── song3.mp3
  │
  ├── quran/
  │   ├── al-fatihah.mp3
  │   └── al-baqarah.mp3
  │
  └── pop/
      ├── my-favorite-song.mp3
      └── another-song.mp3

CATATAN:
--------
- Sistem akan otomatis scan folder setiap kali halaman di-load
- File yang didukung: .mp3, .wav, .ogg, .m4a, .flac
- Nama file akan dijadikan judul lagu (tanpa extension)
- Pastikan nama file tidak mengandung karakter khusus
- Untuk hasil terbaik, gunakan format MP3 dengan bitrate 128-320 kbps

TIPS:
-----
1. Gunakan nama folder dan file yang deskriptif
2. Hindari spasi di nama file, gunakan dash (-) atau underscore (_)
3. Organize musik berdasarkan genre, mood, atau kategori lain
4. Refresh halaman setelah upload file baru untuk update playlist
